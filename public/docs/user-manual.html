1. Logging In

Step 1: Open http://your-domain.com/admin
Step 2: Enter your email and password
Step 3: Click "Sign In"

Default admin credentials: admin@uniworldholidays.com / password

Change the default password immediately after first login via Profile (top-right avatar).

2. Dashboard Overview

After login, you see the Dashboard with:

  • Stats Cards — New enquiries, pending quotes, conversion rate, active bookings, revenue, balance due
  • Today's Calling List — Scheduled calls for today + overdue. Click any row to open the enquiry.
  • Recent Enquiries — Latest 5 enquiries received
  • Recent Payments — Latest 5 payments recorded
Dashboard data refreshes every 30 seconds automatically. Stats are cached for 60 seconds.

3. Setting Up Master Data (First-Time Setup)

Before using the system, populate these in order:

Step 1: Site Settings

Go to User Management → Site Settings
Fill in: Company Name, Phone, WhatsApp, Email, Address, Social Links
These appear automatically on the public website header/footer.

Step 2: Destinations

Go to Content Management → Destinations → Click "New Destination"
Fill: Name, Country, Continent (Domestic/Asia/Europe/etc.), Description, Highlights
Upload Hero Image. Mark as Featured + Active. Save.

Step 3: Tours

Go to Content Management → Tours → Click "New Tour"
Basic Info tab: Title, Destination, Category, Duration (days/nights)
Content tab: Overview (rich text), Highlights, Inclusions, Exclusions
Itinerary tab: Add day-by-day plan (day number, title, description, meals, hotel)
Pricing tab: Starting price, price type
Media tab: Hero image, gallery
Publishing tab: Set Active, Featured, Publish Date
Save. Then go to the Pricing tab (relation manager below the form) to add pricing tiers.

Step 4: FAQs

Go to CMS → FAQs → Add questions grouped by category (General, Booking, Visa, etc.)

Step 5: Blog Posts

Go to CMS → Posts → Create articles with title, content, category, featured image. Mark as Published.

4. Managing Enquiries

Enquiries come from:

  • Website contact form (auto-created with source=website)
  • Sticky enquiry bar on all pages
  • Manually created by staff (WhatsApp, walk-in, referral, etc.)

Enquiry Statuses

StatusMeaning
NewJust received, not yet contacted
ContactedFirst contact made
QuotedQuotation sent to client
ConvertedClient accepted, booking created
LostClient not interested / no response

Actions on Enquiries

WA — Opens WhatsApp with client's number
Quote — Creates a new quotation pre-filled with client data
Contacted — Marks as contacted + updates last_contacted_at
Edit — Opens full enquiry form with Interaction History tab

Filters Available

Status, Source, Assigned To, Destination, Follow-ups Overdue, Unassigned Only, Trashed

5. Follow-ups & Calling

Go to Sales Pipeline → Follow-ups & Calls

Today's Calling List

Shows all calls scheduled for today + overdue calls. Default filter is "Today's Calls".

Logging a Call

Click "Log Call / Follow-up" button at top
Select Client, Type (Call/WhatsApp/Email/Meeting), Status (Completed/No Answer/Busy)
Add notes about the conversation
Set "Next Follow-up" date if needed → auto-creates next scheduled call

From Enquiry Profile

Open any enquiry → Click "Interaction History" tab below the form
Click "Log Interaction" → Records the call and shows full timeline of all past interactions

6. Creating Quotations

From an Enquiry

On Enquiries list → Click "Quote" action on any row
Form pre-fills with client name, phone, email, travel date, pax
Fill: Title (e.g. "Kashmir 5N/6D"), pricing, validity date
Save → You're redirected to the Edit page

Adding Items

On Quotation Edit page → Scroll to "Quotation Items" section
Click "Add Item" → Select Type (Accommodation/Flight/Transfer/Activity/etc.)
Fill: Title, Unit Cost, Quantity → Total auto-calculates
Repeat for all items. Totals update on save.

Sending to Client

Click "Mark as Sent" button at top
→ Status changes to "Sent"
→ Email sent to client with quotation link (if email configured)
→ Click "Copy Link" to share via WhatsApp

Client Actions

Client opens the link → views quotation → can Accept or Decline. You get notified.

Creating a Revision

Click "Create Revision" → Duplicates the quotation as v2
Edit items/pricing → Send again. Old version marked as "Revised".

7. Managing Bookings

Creating from Accepted Quotation

On accepted quotation → Click "Create Booking"
Form pre-fills from quotation data. Booking reference auto-generated (UW-2026-000001).

Adding Travellers

On Booking Edit → "Travellers" tab
Click "Add Traveller" → Fill name, passport, DOB, nationality

Booking Statuses

StatusMeaning
ConfirmedBooking created, no payment yet
Partial PaidSome payment received
Fully PaidAll payments received
CompletedTrip completed successfully
CancelledBooking cancelled
RefundedRefund processed

8. Recording Payments

On Booking Edit → "Payments" tab
Click "Record Payment" → Enter amount, method (Cash/UPI/Bank/Card), date, reference number
Upload receipt if available. Save.
→ Booking balance auto-updates
→ Status auto-changes (partial_paid → fully_paid)

9. CMS Content Management

Pages

About Us, Services, Privacy Policy, Terms — all editable via CMS → Pages. Rich text editor. SEO fields available.

Blog Posts

Create articles with categories, tags, featured image. Published posts appear on /blog.

Testimonials

Add client reviews with name, location, rating, content. Featured ones show on homepage.

Banners

FAQs

Grouped by category. Active FAQs appear on /faq page as accordion.

10. User & Role Management

Creating a New User

Go to User Management → Users → Click "New"
Fill name, email, password → Assign role(s) → Save

Managing Roles

Go to User Management → Roles → Click any role to edit
Each module has a tab with checkboxes for each action (View, Create, Edit, Delete, etc.)
Check/uncheck permissions → Save

Default Roles

RoleAccess
Super AdminEverything
SalesEnquiries, Quotations, Follow-ups, Bookings (view)
OperationsBookings, Travellers, Payments
ContentDestinations, Tours, CMS modules

12. Reports

Three separate report pages (Super Admin only):

  • Sales Report — Enquiry pipeline, source breakdown, quotation win rate, top destinations, monthly trends
  • Revenue Report — Monthly revenue, total collected vs pending, payment method breakdown
  • Bookings Report — Status distribution, monthly bookings, upcoming departures, overdue payments

Exporting Data

On Enquiries or Bookings list → Click "Export" button at top
Select format → Download Excel/CSV file
